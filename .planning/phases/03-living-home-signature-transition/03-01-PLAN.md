<interfaces>
The resolver consumes values already present in one Home forecast snapshot: actual temperature, perceived temperature, weather symbol/condition, and an explicit provider-derived day/night/polar-twilight marker. It must not read the clock, request weather, inspect global state, or infer a different snapshot.

Expose a serializable HomeAtmosphere model with semantic axes rather than component-specific class names. The renderer accepts that model and remains `aria-hidden="true"`; all recommendation and weather meaning continues to live in the existing semantic Home content.
</interfaces>
