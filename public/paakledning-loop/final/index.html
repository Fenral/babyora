3 vinner-mocks: hvilken retning skal Klemeg gå?

Etter 3 runder med /impeccable, /emil-design-eng, /ui-ux-pro-max, /color-expert, /frontend-design og /redesign-existing-projects ble det aldri full konvergens. I stedet krystalliserte tre distinkte vinner-retninger seg. Velg én å gå videre med — eller plukk biter på tvers.

Iter: 3 runder, snitt 72.67 → 71.67 → 75.67 Konvergens: nei (5+ runder regel kicker inn) Dato: 2026-06-25
Retning A · Anatomisk ro

V1 — Stack uten støy

Behold anatomisk plagg-stack. Fjern rail, connector-linjer og legend. ÉN lag-koding (anchor-dot). Lag-info lever i sheet ved tap.

Åpne V1 i full størrelse
  • 4 → 1 lag-koding (kun anchor-dot på selve plagget)
  • Subtil vertikal kropp-akse forsterker anatomi-metaforen
  • CSS-variabler styrer plagg-størrelse + overlap
  • Ikke-destruktiv swap (behold original, render via activeKey)
  • ÉN primær footer-handling + ekstern Tilbakestill når avvik
Retning B · Skannbar liste

V2 — Liste m/ kategori-grupper

Bytt anatomisk stack mot rad-basert liste, gruppert per lag. Mini-stack-preview på toppen for helhetsforståelse. Skalerer trivielt 3–7 lag.

Åpne V2 i full størrelse
  • Kategori-gruppe-overskrift erstatter rail + connector
  • 3-pkt mini-stack-preview gir anatomisk helhet uten støy
  • Material + vekt synlig direkte i rad (mindre tap-pengevinning)
  • "Endret"-badge på rad når plagg avviker fra original
  • Skalerbar til 7+ plagg uten layout-bråk
Retning C · Stack + rail

V3 — Datadrevet rail-connector

Best av iter-3: faktisk anatomisk stack med dynamisk SVG-connector fra plagg til rail-cap. Kategori-label kun via rail-cap (kollapser row-name + legend).

Åpne V3 i full størrelse
  • SVG-connector tegnes fra faktiske anchor-koord (ResizeObserver)
  • 4 → 2 lag-koding (anchor-dot + rail-cap, mistet row-name + legend)
  • OKLCH-kalibrert hue-spread 60-70° for distinkte lag-farger
  • CTA-orange shiftet fra #FF6B35 → #E85A1F (skilt fra ytterst)
  • Datadrevet plagg-størrelse via --w/--h/--overlap custom properties

Hvilken bør du velge?

V2 (Liste) scorer høyest hos /ui-ux-pro-max, /frontend-design og /redesign-existing-projects fordi den eliminerer hele lag-koding-konflikten ved å bruke kategori-overskrifter som primær orden. Skalerer trivielt fra 3 til 7+ lag. Tap: mister noe av den emosjonelle "kledd-på-Liv"-stemningen.

V1 (Anatomisk ro) beholder den emosjonelle anatomi-metaforen som er Klemegs identitet, men dropper alt det /impeccable og /emil-design-eng kalte støy. Sannsynligvis beste valg hvis Sivert prioriterer merke-signatur.

V3 (Stack + rail) er den fullstendige iter-3-pakken med datadrevet connector. Mest informasjonsrik, men også mest visuell støy. Trolig best for ekspert-bruker-modus eller power-user-fane senere.
