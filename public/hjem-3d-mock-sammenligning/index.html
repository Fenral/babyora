Babyora Hjem — V1 / V2 / V3 sammenligning

Tre varianter av samme Hjem-skjerm med identisk brand-system, 3D-vær (sol-Lottie, nedbør-pill, vind-pill) og samme bunn-CTA. Forskjellen ligger i hva som er HERO — avatar, tekst, eller kombinert.

V1

Avatar-hero

Avataren dominerer (~50% av skjermen), tekst er kuttet — bilde alene formidler «kledd for vinter».

V2

Tekst-hero

Stor tekst «Vinterdress, lue og votter» dominerer, avatar er liten visuell bekreftelse under.

V3

Kombinert (eksisterende)

Avatar (220px) + tekst sammen som én enhet — balansert hierarki, bekreftelse ovenfor og under bilde.

Heuristikk-vurdering

5 kriterier vurdert mot Babyora PRODUCT.md kjernemål: rask påkledning, lav kognitiv last, fungerer i kulda med vanter.
