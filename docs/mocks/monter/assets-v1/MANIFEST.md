# Assets v1 — Monter-verdenen (2026-07-31)

Generert med Nano Banana 2, stilreferanser: handoff-mockens filt-ikon (værikoner)
og materiallue-referansen fra retningsrunden (plagg). 1024 px arbeidskopier;
2048 px originaler hos eier/scratchpad. Bakgrunnsfjerning gjøres ved implementering
(image_background_remover, verifisert på maskoten).

Værikoner (på petrol #113B3E): klarvaer, delvis-skyet, skyet, regn, sno, taake, natt.
Plagg (på espresso #2C1F13): kortermet-ullbody (krem), langermet-ullbody (melert),
ull-mellomlag (oker), ullbukse (mose), tynn-lue (krem), lue-med-ull (melert),
votter (rust), ullsokker (krem), vinterdress (petrol), regndress (mose),
halsedisse (melert), toffelsko (rust).

Batch 2b (resterende ~51 plagg fra plagg-katalog.json) genereres med samme
prompt-skjelett når settet er eier-godkjent.
