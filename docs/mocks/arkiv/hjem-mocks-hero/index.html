Babyora Hjem — hero-varianter

3 standalone HTML-mocks som varierer hva som er hero. Samme data på tvers (−4° klarvær, Elverum, anbefaling "Vinterdress + lue + votter"). F60-palett: warm-grey #DBD8D2, terracotta CTA #B4502E, Schibsted Grotesk.

V1 · Avatar-hero

Avataren ER hero. Ingen tall, ingen meta-pills — figuren forteller alt på ett blikk.

V2 · Tekst-hero

Anbefalingen som typografi. Mor leser i hansker på 50 ms — ord, ikke figur.

V3 · Kombinert

Avatar + tekst som ÉT hero-felt. Visuell anker + verbal bekreftelse.
