Direction contract

v0.1 separates evidence-locked product behavior from visual choices that target-dad testing may still change.

Evidence-locked

  • Result before explanation and the observed information order.
  • 18 px mobile gutter, one dominant region, and 44 px controls.
  • Complete canonical outfit in dressing order.
  • Safety, weather age, stale data, offline state, and recovery actions stated in words.

Open until TASK-006

  • Palette values, font personality, serif use, radii, elevation, and illustration style.
  • Component density and motion timing, without changing reading order or reduced-motion behavior.
  • Root destinations: the live visual reference has four slots; local source has three root tabs. Confirm before implementation.

Colors

Pale Nordic green creates the room; warm-white surfaces hold decisions. Evergreen owns structure, terracotta owns genuine action, and semantic colors always pair with words or icons. Dark mode is a companion palette, not an inversion.

Do's and don'ts

Specific guardrails keep the system useful when new screens and agents extend it.

✓ Do

  • Keep the answer before explanation.
  • Use the audited four-slot live shell as the visual reference; confirm root destinations before implementation.
  • Use one emphasized action.
  • Show weather age, reason, and safety boundary in text.
  • Let imagery support canonical garment names.
  • Allow layout to grow vertically with larger text.

✗ Don't

  • Turn Home into a weather dashboard.
  • Use cuteness as evidence.
  • Spread terracotta across decoration.
  • Place serif on instructions or safety.
  • Create a card for every line.
  • Use color, opacity, animation, or a baby character as the only carrier of meaning.
