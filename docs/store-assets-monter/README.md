# App Store-rammer (Monter)

Kode-mal, ikke genererte bilder: `appstore-frames.html` rendres via headless
browser med selector-screenshot per ramme (#f1/#f2/#f3) i eksakt 1290x2796
(iPhone 6,7"). Skjermbildene inni er de ekte verifiserte mock-skjermene fra
docs/mocks/monter/. Ved skjermendringer: bytt PNG-ene, re-render — sekunder,
ikke designtimer. Andre storrelser lages ved a endre .frame-dimensjonene
(6,9": 1320x2868; 5,5": 1242x2208). App Preview-video: fanges fra faktisk
app/simulator ved implementering (aldri generert), maskot-idle + scan brukes
som B-roll.
