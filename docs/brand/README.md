# Babyora logo system

**Status:** Production candidate for owner review. The assets are not wired into
the running app yet.

## Brand idea

The symbol evolves the approved **Beskyttet kjerne / Protected core** direction.
A warm core represents the child. Two soft, asymmetric forms embrace it and
suggest clothing layers, shelter and adaptation without using a literal baby,
heart, shield, cloud or garment.

The silhouette is deliberately organic. It should feel cared for rather than
engineered, while retaining enough geometric discipline to work at app-icon
size.

## Palette

- Morgennatt plum: `#211B32`
- Warm core coral: `#EE9373`
- Canvas lavender: `#DAD8EE`
- Reverse cream: `#F3F2FB`
- App-icon night: `#1A1828`

Mint is not part of the primary logo. In Babyora, mint already communicates
actions and active states; using it in the identity would weaken that semantic
role.

## Wordmark

The wordmark uses an outlined, shaped Fraunces SemiBold base. Its broad forms
connect it to Babyora's existing editorial display typography while remaining
robust enough for product use. The delivered SVG contains paths rather than
live text, so it does not depend on the font being installed.

## Usage rules

- Use the full-colour symbol on light, quiet backgrounds.
- Use the reverse lockup on Morgennatt or temperature-dark backgrounds.
- Use the monochrome symbol when colour reproduction is unreliable.
- Preserve clear space equal to the coral core's diameter around the mark.
- Do not add shadows, outlines, facial features, weather icons or gradients.
- Do not replace coral with mint; mint remains an interaction colour.

## Origin and review

Higgsfield Recraft V4.1 was used for a controlled vector exploration of the
protected-core metaphor. The selected geometry was then cleaned, recoloured to
Babyora's existing tokens and combined with a separately outlined wordmark.
Google Image research is reference-only; no third-party image or logo is used
in the delivered assets.
