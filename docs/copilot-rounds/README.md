# Copilot-rounds (F28-loop fasit-rolle)

**Aktiveres ved:** V0-saldo ≤ $0.50 (per F30-protokoll, plan-fila).

**Hvor å starte:**
- Les `../v0-rounds/HANDOVER-TO-COPILOT.md` for full V0-historikk +
  score-tabell + V0-sitater + a11y-policy + loop-protokoll
- Lagre Copilot-respons per runde her som `F28.X-skjerm-respons.md`
  (samme struktur som `../v0-rounds/`)

**Status (2026-06-19):** ikke aktivert. V0-saldo $2 ved oppstart av
F30. Filene her vil bli populert ved bytte.

## Filnavn-konvensjon (samme som v0-rounds)

```
F28.X-skjerm.md
F28.X-skjerm-runde2.md     # ved flere runder per skjerm
F28.X-skjerm-SHIP.md        # når skjermen blir SHIP-verdiktet
```

## Hva som lagres per runde

1. Chat-URL (https://github.com/copilot/...)
2. Copilot's score 0-100
3. Verbatim sitater av de viktigste innsikter
4. Tiltak-tabell (# / Tiltak / Hvor / Pri)
5. Min (Claude's) anbefaling om hva som implementeres + hva som
   trenger Sivert-godkjenning

Identisk struktur som `../v0-rounds/F28.X-*.md`.
