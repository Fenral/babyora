# F60.15 — Pixel-perfect Dark-mode Sjekkliste

> Atomisk verifiseringsliste for dark-mode-implementering (workflow `w33e5cr24`).
> Bruk sammen med `scripts/F60.15-pixperfect.mjs` for automatisk Playwright-kjøring.
>
> **Test-matrise:** 11 skjermer × 3 theme-modi (auto / light / dark) = **33 viewer**.
> **Viewport:** 390 × 844 (iPhone 13/14 device-frame, Klemeg mobile-first).
> **Base-URL:** `https://wool-app.vercel.app/` (default) eller `WOOL_BASE_URL` env-var.
>
> Hvert check er én linje, AUT/MANuell merket. AUT = Playwright kan verifisere
> uten menneske; MAN = krever visuell vurdering på lagret screenshot.

---

## Globale checks (på tvers av alle skjermer)

### Theme-mekanikk
- [ ] **AUT** `document.documentElement.dataset.theme === 'dark'` etter dark-toggle
- [ ] **AUT** `document.documentElement.dataset.theme === 'light'` etter light-toggle
- [ ] **AUT** `document.documentElement.hasAttribute('data-theme') === false` i auto-mode
- [ ] **AUT** `localStorage["babyora.theme"]` persisteres mellom reloads (`{"state":{"mode":"dark"},"version":0}`-form)
- [ ] **AUT** Ingen FOUC: `<html>` har korrekt `data-theme` FØR React mounter (boot-script i `index.html`)
- [ ] **AUT** `:root` `--bg-canvas` resolver til `oklch(0.21 0.005 65)` i dark, `#DBD8D2` i light
- [ ] **AUT** `:root` `--warm-orange-500` resolver til `oklch(0.76 0.180 47)` i dark, `#FF6B35` i light
- [ ] **AUT** `:root` `--ink-900` har OKLCH L ≥ 0.93 i dark, ≤ 0.20 i light
- [ ] **AUT** `prefers-color-scheme: dark` i auto-mode = dark-tokens aktive (uten `data-theme`)
- [ ] **AUT** Theme-bytte trigger ingen layout-shift (CLS-måling ≈ 0)

### BottomTabBar (global)
- [ ] **AUT** `<nav aria-label="Hovednavigasjon">` finnes
- [ ] **AUT** Aktiv tab har `aria-current="page"`
- [ ] **AUT** Alle 4 tab-knapper ≥ 44×44 px (WCAG 2.5.5)
- [ ] **AUT** Bar bg = `var(--surface)`, top-border = `1px var(--ink-200)`
- [ ] **AUT** Aktiv-pill bruker `var(--terracotta-600)` som farge-token
- [ ] **AUT** `safe-area-inset-bottom` respektert (`env(safe-area-inset-bottom)` i style)
- [ ] **MAN** Aktiv-pill kontrast mot bar-bg synlig i både light og dark

### Tilgjengelighet (alle skjermer)
- [ ] **AUT** `<html lang="nb">` satt
- [ ] **AUT** Body-tekst computed `color` har AA 4.5:1 mot `--bg-canvas` (begge moduser)
- [ ] **AUT** Ingen tekst med opacity < 0.6 på low-emphasis-elementer (kontrast-felle)
- [ ] **AUT** Focus-ring synlig på alle interaktive elementer (Tab-navigering)
- [ ] **AUT** Touch-targets ≥ 44×44 (sample 3 CTAs per skjerm)

### Innstillinger-spesifikt (Utseende-toggle)
- [ ] **AUT** 3-vei segment-control med aria-labels "Auto", "Lys", "Mørk"
- [ ] **AUT** Valgt segment = `aria-pressed="true"` ELLER `aria-selected="true"`
- [ ] **AUT** Tap på "Mørk" → `<html data-theme="dark">` umiddelbart
- [ ] **AUT** Tap på "Auto" → `<html>` har ikke `data-theme`
- [ ] **MAN** Segment-control selv leselig i begge moduser

## Output-format

Script genererer `screenshots/F60.15-report.md` med:

```
🟢 PASS — 287/297 checks
❌ FAIL — 10 checks (se nedenfor)

[hjem · dark] ❌ avatar-glow var(--avatar-glow) ≠ forventet rgba(245,235,220,0.4)
   → actual: rgba(255,255,255,0.55) — sannsynlig: dark-override mangler

[innstillinger · light] ❌ segment-control "Mørk" har ikke aria-pressed=true
   → element: button[data-theme-mode="dark"]
```

Exit-code: `0` om alle PASS, `1` om noen FAIL.
