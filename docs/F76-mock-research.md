# F76 — Mock Research (10 design-stiler for Babyora)

Referanse-bilder + URLs samlet via Mobbin MCP for Hjem + Uke-mocks.
Hver stil har 2–3 referanser med DNA-relevans (ikke nødvendigvis 1:1 vær-app).
Hentet 2026-06-30.

---

## v1 — Brutalist Mono
**DNA:** Raw, monospaced, hard borders. No gradients, no soft shadows. Information-dense but breathing. Pixel-grid feels intentional.

**Inspirasjon:** Vercel docs raw mode, Linear changelog, OK Computer album sleeve grid.

**Mobbin-referanser:**
1. **one year (iOS)** — friday 01.02 / 2026 capsule labels, monospaced UI badges, pixel-dot grid that fills the screen as the year passes. Pure brutalist intent: violet-on-bone, no decoration. https://mobbin.com/screens/8ce281b6-ebee-4eb0-a5e4-78c0a10d9644
2. **one year (iOS) — settings entry** — same pixel-grid, but reduced to year-cluster + single "Settings" pill. Shows how brutalist-mono breathes when you remove 90% of the dots. https://mobbin.com/screens/87c47389-25b1-4958-9e25-ae2ccffd101f
3. **Replit (web) — Agent + Database split view** — mono-typed query results, dense tabular layout, no gradients, hard panel borders. Translates the brutalist-mono DNA to data-grid form. https://mobbin.com/screens/7506be07-3fb0-4738-95c0-b1706b708084

**Babyora take:** Day chips as `MAN 30/06` mono caps. Temperature as raw `+18°C` mono. Plagg-rad with `|` separators, no card-fills. Pixel-grid dot row under header.

## v2 — Editorial Magazine
**DNA:** Print-magazine layout. Asymmetric grid. Pull quotes from weather data. Generous tracking on caps.

**Inspirasjon:** Aesop website, Kinfolk magazine, Apartamento layout.

**Mobbin-referanser:**
1. **Tolan (iOS) — "The Relay"** — huge serif display headline, hairline divider rule, body-set caption pulled into magazine column. Exactly the editorial pull-quote feeling we want for "+18° / let bris". https://mobbin.com/screens/d8e3ba51-2e42-4d98-b587-53b051d15380
2. **NYTimes (iOS) — Wirecutter Recommendation** — section eyebrow ("NEWSLETTER"), serif story title, photographic anchor below, asymmetric vertical rhythm. Direct model for Babyora hero. https://mobbin.com/screens/e8a3eee0-9507-4b8a-83c7-f6a21167a931
3. **NYTimes (iOS) — "ON LOCATION" feature** — small-caps section label, big serif lede, sober body type, byline + date. The cleanest possible editorial chrome — perfect for Uke-oversikten som "ukens forhåndsvisning". https://mobbin.com/screens/0fb385af-382d-4ef4-b26f-64cf3bb0d0ca

**Babyora take:** "UKENS VÆR" som small-caps eyebrow. Serif display "Bløtt + 18° i morgen". Plagg-listen som magazine-byline ("STRØMPER · BODY · ULL-OVERDEL").

## v3 — Tactile Glass
**DNA:** iOS 16–26 glass-morphism done right (intentional, sparse). Frosted bg cards, subtle inner shadows, depth via blur.

**Inspirasjon:** Apple Weather iOS 17, Linear Mac app sidebar, iOS Lock Screen widgets.

**Mobbin-referanser:**
1. **Apple Weather (iOS) — Los Angeles 10-day** — kanonisk: cloudy gradient background, frosted "10-DAY FORECAST" card, temp-bars med soft glow. Dette ER referansen. https://mobbin.com/screens/c56345fa-fc98-445f-9a38-3c8b44297e28
2. **Apple Weather (iOS) — Jakarta** — heltevær-blur som hero, kompakt frostet info-rektangel, hourly chips med inner-shadow. Viser hvordan glass jobber mot foto-bakgrunn. https://mobbin.com/screens/3f737f9f-363b-47a5-b4ab-a8afbf237c4e
3. **Apple Weather (iOS) — detail-grid (Wind/Sunset/Visibility/Humidity)** — sparse glass-bento, hver tile er en separat frostet flate, dybde via blur kun. Perfekt mønster for Babyora plagg-tiles. https://mobbin.com/screens/76bd3242-e04d-4bc0-b20a-305870075019

**Babyora take:** Vær-foto eller gradient-himmel som hero-bakgrunn. Frostet "I DAG / DENNE UKEN" kort med 18° + plagg-stack. Plagg som glass-tiles i 2×3 grid (body, strømper, ull, fleece, dress, lue).

## v4 — Things Zen
**DNA:** Ultra-clean. Hairlines for separators. Negative space carries hierarchy. Calm.

**Inspirasjon:** Things 3, Bear app, Notion clean theme.

**Mobbin-referanser:**
1. **Things 3 (iOS) — Sidebar** — Quick Find chip på topp, ikoner+labels med rik hvit luft, en hairline-divider, single FAB. Den definitive kalibreringen av "calm". https://mobbin.com/screens/a10c7d97-a672-486a-9502-194c017a76fc
2. **Things 3 (iOS) — Grocery shopping item-expanded** — checklist-rader med hairline-separatorer, soft "Errand/Important" capsules, rolig metadata-rad. Tone-perfekt for plagg-liste. https://mobbin.com/screens/bc8c7688-15a0-44d3-9f57-15531c3f5f7a
3. **Things 3 (iOS) — Project 101** — to oppgaver, all white space ellers. Viser hvordan "tomt" føles bevisst, ikke uferdig. Babyora "I dag"-skjerm kan være så sparsom. https://mobbin.com/screens/0afbb222-e355-4a5d-bfc9-52f1cb4d8733

**Babyora take:** Bare "I dag · 18°" sentrert øverst, hairline, så plagg-rader som checklist. Ingen kort, ingen skygger. Hvit + kullsvart text + én accent (sand).

## v5 — Linear Precision
**DNA:** Dark + grid + IBM Plex Mono labels. Data-dense. Hover lines visible. Semantic color for state.

**Inspirasjon:** Linear, Vercel dashboard, Raycast UI.

**Mobbin-referanser:**
1. **Linear (web) — AS Mobbin Issues (list view)** — alle issue-ID som mono caps (AS-11, AS-9), status-dots, semantic chips, hairline-row separation. Direkte mal for Babyora plagg-rader. https://mobbin.com/screens/e142df2a-3527-499c-8f81-1b715947ac0c
2. **Linear (web) — Active/Backlog kanban-kolonner** — kort med mono-ID + status-dot + label-pill. Viser hvordan presision-stil oversettes til kort-form. Bra for Uke-kolonner (man–søn). https://mobbin.com/screens/720724d3-f686-457f-8c00-fa7efa409b12
3. **Linear (web) — SLM Mobbin issues** — alt med mono-ID, semantic chips ("Improvement", "3rd Party"), tight row-height. Det perfekte data-dense referansen. https://mobbin.com/screens/6c3db6e0-7d6a-4d93-bd22-4fbaf0a539e3

**Babyora take:** Mørk bg (#0F1115). Dag-rader: `MAN-30` (mono ID) · status-dot · `+18°C lett bris` · plagg-chips (`body`, `ull`, `dress`). State-farger for kalde/våte dager.

## v6 — Carrot Quirky
**DNA:** Strong illustrated character. Weather data delivered with personality (but warm, not snarky). Big avatar.

**Inspirasjon:** Carrot Weather, Headspace, Reflectly.

**Mobbin-referanser:**
1. **CARROT Weather (iOS) — AR-orb med karakter-monolog** — temperatur-orb som hero, karakter-stemme i tekstrute under ("…I thought I was beautiful just the way I was"). Karakter-først-tone vi vil etterligne (men varmere). https://mobbin.com/screens/d7303ff6-abb4-47f2-8459-26cbe10dcd78
2. **CARROT Weather (iOS) — Karakter-tag-banter** — viser hvordan en sentral karakter bærer hele UI-en + leverer data som dialog. https://mobbin.com/screens/45723279-c825-41e3-98b9-f029525f5ef4
3. **CARROT Weather (iOS) — 88° orb med swipe-prompt** — karakter blir orb, temp er stor, instruksjon som kosete tekstrute. Babyora-versjonen: tegnet baby/ulldukke + "Pakk inn meg i ull i dag, det er bløtt!" https://mobbin.com/screens/12437dde-c845-4b8c-a049-f610bf309a3b

**Babyora take:** Stor illustrert "Lo"-baby (samme støvkanin-figur, varmere). Tekstrute: "I dag er det 18° og lett bris — du klarer deg med body og ull-overdel ☁️". Plagg som kosete sticker-ikoner.

## v7 — Notion Blocks
**DNA:** Block-based composition. Drag-feel even if non-interactive. Mixed-density rows.

**Inspirasjon:** Notion, Coda, Craft.do.

**Mobbin-referanser:**
1. **Notion (iOS) — Test table med cover image** — page header med cover (astronaut), ikon+title-block, beskrivelse-block, så board-blokk under. Direkte mønster for Babyora "Uke"-side: cover + dag-blokker. https://mobbin.com/screens/e77e46d7-ce63-4071-9db4-ff9403b4b4e9
2. **Notion (iOS) — Team Home med inline tabell** — emoji-prefiks rader (⭐ What's New, 🚩 Team Mission), `Resources` section, embedded table med filter-chips. Viser mixed-density: link-rader + tabell-rad side om side. https://mobbin.com/screens/20a95974-c4be-413d-b9be-f8f63228932d
3. **Notion (iOS) — Team Home empty state** — samme blokk-skjelett, men tom tabell ("Empty. Click to add a row.") Babyora-bruk: dag-rad med "Ingen prognose ennå". https://mobbin.com/screens/6bdb280c-2f12-4276-b6cf-b70b843517ad

**Babyora take:** Hver dag = en blokk-side. Cover = vær-foto. Toggle-blokker: "Plagg ▸ body, ull, dress". Inline tabell-blokk for time-for-time temp.

## v8 — Aesop Luxury
**DNA:** Spa-grade restraint. Warm neutrals. Editorial spacing. Avatar as fine sculpture.

**Inspirasjon:** Aesop, Le Labo, Apartamento product detail.

**Mobbin-referanser:**
1. **HODINKEE (web) — Omega Seamaster product page** — small-caps eyebrow ("OMEGA"), heavy serif product-name, prislinje med disclosure, "Dig Deeper"-seksjon med to-kolonne magasin-grid. Luksus-ro vi vil ha. https://mobbin.com/screens/f57c86a4-ccdb-442b-871b-c42677b9e951
2. **HODINKEE (web) — Grand Seiko skim-detail** — serif lede til venstre, foto-still-life til høyre på blå-kalkkrukke-bakgrunn. Warm-neutral tone, ingen UI-støy. Nøyaktig den editorial-spa-følelsen. https://mobbin.com/screens/6e7902d3-688c-47b4-b397-de4bdceba27a
3. **Blue Apron (web) — Groundwork wine product** — Profile/Tannin/Sweetness chart med håndskrift-serif label, tooltip overlay. Luksus-data uten å være data-dashboard. God modell for "vær-profil for dagen". https://mobbin.com/screens/2fee7400-b2e0-4926-8c42-855b013a7f64

**Babyora take:** Beige bakgrunn (#F2EDE3). Serif display "I dag, 30. juni". Subtittel som magasin-byline. Plagg-listen som ingrediens-rad med håndskrift-serif. Ett still-life-foto av en ullbody.

## v9 — Data Instrument
**DNA:** TrackMan/Garmin influence. Numeric primary. Charts integrated. Data-first.

**Inspirasjon:** TrackMan iOS, Whoop, Garmin Connect.

**Mobbin-referanser:**
1. **WHOOP (iOS) — Day Strain 12.8 / Recovery 57% / Sleep 5:51 (camera overlay)** — tre store metric-pillar nederst, navn under tall. Akkurat det "data-first" hierarkiet vi vil ha for Babyora (Temp / Vind / Lag). https://mobbin.com/screens/cf1a07d4-3276-47c8-b7d5-bb19220babc1
2. **WHOOP (iOS) — Overview med dual-ring** — Recovery + Strain som konsentriske ringer, HRV + Sleep% inni, navigasjonstaber som mono-caps. Mal for Babyora "lag-anbefaling-ring" + temperatur sentralt. https://mobbin.com/screens/6a012278-d01c-473e-b860-3c08e35311ed
3. **WHOOP (iOS) — Strain 12.8 detail** — massiv numerisk hero ("12.8"), arc-progress rundt, forklarende paragraf under. Den reneste instrument-stilen. Babyora-port: stor "+18°", arc viser "kjøletall", forklaring under. https://mobbin.com/screens/aac78ccc-35b7-459d-abe3-5256ba4dfd6b

**Babyora take:** Hero-tall (følt temp), ring (vindkjøling), tre stat-piller (TEMP / VIND / LAG-INDEKS). Mono labels. Sort bakgrunn.

## v10 — Warm Photo-led
**DNA:** Large photographic hero of baby/clothing. Rest of UI subordinate. Editorial photography aesthetic.

**Inspirasjon:** Hers landing, Helia (parenting), Aether (apparel).

**Mobbin-referanser:**
1. **Lifesum (iOS) — full-bleed portrait hero** — varm portrait dekker 80% av skjermen, serif "Healthy eating. Simplified." nederst, én primary CTA. Foto bærer hele skjermen. https://mobbin.com/screens/584811fc-dd63-4f44-abc1-6d8def80f3cb
2. **Open (iOS) — "A place to come to your senses"** — kinematisk dobbel-portrett, sentrert serif title midt i bildet, taber nederst. Editorial-aesthetic, ingen UI-chrome. https://mobbin.com/screens/8d0df82d-96ab-428c-95e0-69797cde2a7a
3. **Hers (iOS) — Consultation hero** — varm portrait med chat-bobler over, sober header, én CTA. Direkte "varm helse"-tone som matcher Babyora baby-domene. https://mobbin.com/screens/c9f33975-9dd9-41f8-b1d2-3cfceede608b

**Babyora take:** Full-bleed foto av baby i ullbody utendørs. Serif lede "I dag er det 18° — pakk dem mykt". Plagg-anbefaling som diskret chat-boble over foto. Ingen kort, ingen UI-skygger.
